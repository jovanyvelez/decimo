mission_briefing

// ¿Por qué los bucles cualitativos cambian todo?
15 MIN
Imagina un videojuego. ¿Sabes cuántas veces el jugador va a presionar "saltar"? No. ¿Sabes cuántos intentos tomará escribir una contraseña correcta? No. ¿Sabes cuántos productos va a escanear el cajero? No. Los bucles cuantitativos no sirven aquí. Necesitas algo que escuche el mundo y reaccione.

La diferencia fundamental

🔢 Bucle Cuantitativo

for (int i=0; i<10; i++)
Sabes el número exacto de iteraciones antes de empezar.

🎯 Bucle Cualitativo

while (comando != "salir")
El número depende del estado del sistema o del usuario.

🚨 Bucle de Validación

do {...} while (!valido);
Se ejecuta al menos una vez y repite hasta que la entrada es correcta.

⚠
ALERTA: El Bucle Infinito
Un bucle cualitativo mal diseñado puede volverse infinito: el programa nunca termina y tienes que forzar el cierre. Esto se llama "infinite loop" y es el enemigo número 1 de todo hacker novato. Aprenderás a prevenirlo.
01

¿Cuándo parar?

// El misterio de la Entrada Abierta
45 MIN100 XP
Imagina un chatbot. El usuario escribe mensajes sin límite. ¿Cómo sabes cuándo termina? No lo sabes. Solo puedes reaccionar: si escribe "salir", te detienes. Si escribe otra cosa, respondes y sigues esperando. Ese es el corazón de un bucle cualitativo.

Anatomía del while

// while: evalúa ANTES de entrar
while (condición)
{
    // Solo entra si la condición es true
    // Si es false desde el inicio,
    // no se ejecuta NI UNA VEZ
}
// Ejemplo: chat infinito
string cmd = "";

while (cmd != "salir")
{
    Console.Write("> ");
    cmd = Console.ReadLine();
    // procesar comando...
}
// aquí salimos
💡
Patrón clave: el centinela
La palabra o valor que "rompe" el bucle se llama centinela (sentinel). En el ejemplo anterior, "salir" es el centinela. Puede ser un string, un número negativo, un bool, o cualquier valor que señale "aquí termina".

💻 Código completo en C#

ChatBot.cs
using System;

class ChatBot
{
    static void Main()
    {
        Console.WriteLine("🤖 ChatBot iniciado. Escribe 'salir' para terminar.\n");

        // ═════════════════════════════════════════
        // CENTINELA: variable de control cualitativa
        // ═════════════════════════════════════════
        string comando = "";   // inicia vacío (NO es "salir")

        // ═════════════════════════════════════════
        // BUCLE CUALITATIVO: depende del estado
        // ═════════════════════════════════════════
        while (comando != "salir")
        {
            Console.Write("> ");
            comando = Console.ReadLine();

            switch (comando.ToLower())
            {
                case "hola":
                    Console.WriteLine("👋 ¡Hola, humano!");
                    break;
                case "hora":
                    Console.WriteLine($"🕐 Son las {DateTime.Now:HH:mm}");
                    break;
                case "chiste":
                    Console.WriteLine("😄 ¿Por qué los programadores prefieren el modo oscuro? Porque la luz atrae bugs.");
                    break;
                case "salir":
                    Console.WriteLine("👋 Hasta luego.");
                    break;
                default:
                    Console.WriteLine("🤔 No entiendo ese comando.");
                    break;
            }
        }

        Console.WriteLine("\n🔚 El bucle terminó. Sesión cerrada.");
    }
}

02

El Centinela y las Validaciones

// Algoritmos defensivos con do-while
45 MIN100 XP
El mundo real es hostil: los usuarios escriben letras cuando pides números, dejan campos vacíos, ponen contraseñas débiles. Un programa robusto no se rompe ante esto — valida y vuelve a pedir. Aquí entra el do-while.

Diferencia crítica con while

// while: pregunta PRIMERO
while (condición)
{
    // Si la condición es false
    // desde el inicio, NO se
    // ejecuta ni una vez.
}
// do-while: ejecuta PRIMERO
do
{
    // Se ejecuta AL MENOS
    // una vez, sin importar
    // la condición inicial.
} while (condición);
💡
Regla de oro
Usa do-while cuando necesites que algo pase al menos una vez: pedir una contraseña, pedir una opción de menú, leer un dato del usuario. El 90% de las validaciones de entrada usan do-while.

💻 Código completo en C#

PasswordValidator.cs
using System;

class PasswordValidator
{
    static void Main()
    {
        Console.WriteLine("🛡 SecureAuth v2.1\n");

        bool esValida;
        string password;
        int intentos = 0;

        // ═════════════════════════════════════════
        // DO-WHILE: se ejecuta AL MENOS UNA VEZ
        // ═════════════════════════════════════════
        do
        {
            Console.Write("Contraseña: ");
            password = Console.ReadLine();
            intentos++;

            // Validación cualitativa (4 reglas)
            esValida = ValidarPassword(password);

            if (!esValida)
            {
                Console.WriteLine("❌ No cumple los requisitos. Reintenta.\n");
            }

        } while (!esValida);   // ← la condición va al final

        Console.WriteLine($"\n✅ Acceso concedido en {intentos} intento(s).");
    }

    // ═════════════════════════════════════════
    // Validación cualitativa con banderas
    // ═════════════════════════════════════════
    static bool ValidarPassword(string pwd)
    {
        if (pwd.Length < 8)
        {
            Console.WriteLine("  ⚠ Mínimo 8 caracteres.");
            return false;
        }

        bool tieneMayuscula = false;
        bool tieneNumero    = false;
        bool tieneSimbolo   = false;

        foreach (char c in pwd)
        {
            if (char.IsUpper(c))   tieneMayuscula = true;
            if (char.IsDigit(c))   tieneNumero    = true;
            if ("!@#$%&*".Contains(c)) tieneSimbolo = true;
        }

        if (!tieneMayuscula) Console.WriteLine("  ⚠ Falta mayúscula.");
        if (!tieneNumero)    Console.WriteLine("  ⚠ Falta número.");
        if (!tieneSimbolo)   Console.WriteLine("  ⚠ Falta símbolo.");

        return tieneMayuscula && tieneNumero && tieneSimbolo;
    }
}
⚠
Punto y coma obligatorio
El do-while es la única estructura de control en C# que termina con ; después del paréntesis de la condición. Si lo olvidas, no compila. El while normal NO lleva punto y coma al final.
03

Banderas de Control de Estado

// Interruptores de emergencia para romper ciclos
45 MIN100 XP
A veces necesitas más de una razón para detener un bucle. O tal vez el bucle depende de algo que cambia en el tiempo: ¿se quedó sin batería? ¿encontró al enemigo? ¿excedió el tiempo? Las banderas (flags) son variables booleanas que actúan como interruptores de emergencia.

¿Qué es una bandera?

Una bandera es simplemente una variable bool que recuerda si algo ocurrió. Se inicializa en false, y cuando el evento sucede, se cambia a true. El bucle la revisa constantemente.

// Patrón básico
bool juegoTerminado = false;

while (!juegoTerminado)
{
    // lógica del juego...

    if (vidas == 0)
        juegoTerminado = true;
}
// Múltiples banderas
bool sinVidas  = false;
bool sinTiempo = false;
bool gano      = false;

while (!sinVidas &&
       !sinTiempo &&
       !gano)
{
    // jugar...
}

💻 Código completo en C#

SecuritySystem.cs
using System;
using System.Threading;

class SecuritySystem
{
    static void Main()
    {
        Console.WriteLine("🚨 Sistema de seguridad iniciado\n");

        // ═════════════════════════════════════════
        // BANDERAS: una por cada posible evento
        // ═════════════════════════════════════════
        bool motionDetected = false;
        bool doorOpen       = false;
        bool windowBroken   = false;
        bool alerta         = false;  // bandera maestra
        int ciclos = 0;
        Random rnd = new Random();

        // ═════════════════════════════════════════
        // Bucle mientras no haya alerta
        // ═════════════════════════════════════════
        while (!alerta)
        {
            ciclos++;
            Console.WriteLine($"[Ciclo {ciclos}] Monitoreando...");

            // Simulación: eventos aleatorios
            if (rnd.Next(10) == 0) motionDetected = true;
            if (rnd.Next(15) == 0) doorOpen       = true;
            if (rnd.Next(20) == 0) windowBroken   = true;

            // ═════════════════════════════════════
            // ¿Alguna bandera se activó?
            // ═════════════════════════════════════
            if (motionDetected || doorOpen || windowBroken)
            {
                alerta = true;
                Console.WriteLine("\n🚨 ¡INTRUSO DETECTADO!");

                if (motionDetected) Console.WriteLine("  → Sensor de movimiento");
                if (doorOpen)       Console.WriteLine("  → Puerta abierta");
                if (windowBroken)   Console.WriteLine("  → Ventana rota");

                break;  // salida forzada del bucle
            }

            Thread.Sleep(500);
        }

        Console.WriteLine($"\n🔚 Sistema detenido tras {ciclos} ciclos.");
        Console.WriteLine("📞 Llamando a seguridad...");
    }
}
!
El poder de break
break saca del bucle inmediatamente, sin esperar a que la condición se evalúe. Es útil cuando detectas una condición crítica dentro del cuerpo. Pero no abuses: usar banderas es más limpio y legible que llenar el código de break.

💻 Código completo en C#

SuperCashier.cs
using System;

class SuperCashier
{
    static void Main()
    {
        Console.WriteLine("💰 SuperCashier Pro\n");

        // ═════════════════════════════════════════
        // 1. INICIALIZAR VARIABLES
        // ═════════════════════════════════════════
        double total = 0;
        int count = 0;
        bool esVIP = false;
        string entrada = "";
        const double LIMITE_VIP = 100.0;

        // ═════════════════════════════════════════
        // 2. BUCLE while DE ENTRADA ABIERTA
        // ═════════════════════════════════════════
        while (entrada != "PAGAR")
        {
            Console.Write("Producto (o 'PAGAR'): ");
            entrada = Console.ReadLine();

            if (entrada == "PAGAR") break;

            // ═════════════════════════════════════
            // 3. do-while DE VALIDACIÓN
            // ═════════════════════════════════════
            double precio;
            bool precioValido;

            do
            {
                Console.Write("Precio: $");
                precioValido = double.TryParse(Console.ReadLine(), out precio);

                if (!precioValido || precio <= 0)
                {
                    Console.WriteLine("❌ Ingresa un número positivo.");
                    precioValido = false;
                }
            } while (!precioValido);

            // ═════════════════════════════════════
            // 4. ACUMULAR
            // ═════════════════════════════════════
            total += precio;
            count++;
            Console.WriteLine($"✓ {entrada} añadido. Total: ${total:F2}\n");
        }

        // ═════════════════════════════════════════
        // 5. BANDERA DE LOGRO
        // ═════════════════════════════════════════
        if (total > LIMITE_VIP)
        {
            esVIP = true;
        }

        // ═════════════════════════════════════════
        // 6. IMPRIMIR TICKET
        // ═════════════════════════════════════════
        Console.WriteLine("\n════ TICKET FINAL ════");
        Console.WriteLine($"Productos: {count}");
        Console.WriteLine($"Subtotal:  ${total:F2}");

        if (count > 0)
        {
            Console.WriteLine($"Promedio:  ${total / count:F2}");
        }

        if (esVIP)
        {
            double desc = total * 0.10;
            Console.WriteLine($"\n⭐ ¡LOGRO VIP! -10%: -${desc:F2}");
            Console.WriteLine($"TOTAL: ${total - desc:F2}");
        }
        else
        {
            Console.WriteLine($"TOTAL: ${total:F2}");
        }
    }
}

Arena: Bug Hunter

// Encuentra el bucle infinito
45 MIN150 XP
Hora de la verdad. Aquí hay 3 códigos con bugs que crean bucles infinitos o lógicamente incorrectos. Tu misión: identificar el error y corregirlo. Cada bug que encuentres te acerca al rango de Master Hacker.
BUG #1
El contador olvidado
Este código debería contar del 1 al 5, pero en realidad... nunca termina. ¿Por qué?
int i = 1;

while (i <= 5)
{
    Console.WriteLine(i);
    // ← falta algo aquí
}
Añadir Console.ReadLine(); dentro del bucle
Añadir i++; dentro del bucle
Cambiar while por do-while
Cambiar la condición a i >= 5
BUG #2
La bandera zombie
Este juego debería terminar cuando el jugador escriba "salir", pero la bandera nunca cambia. ¿Dónde está el error?
bool jugando = true;
string comando;

while (jugando)
{
    Console.Write("> ");
    comando = Console.ReadLine();

    if (comando == "salir")
    {
        Console.WriteLine("Saliendo...");
        // ← falta la línea crítica
    }
    else
    {
        Console.WriteLine($"Ejecutando: {comando}");
    }
}
Añadir break; después de continue;
Añadir comando = "";
Añadir jugando = false; dentro del if
Cambiar while (jugando) por while (!jugando)
BUG #3
El do-while invertido
Este validador de número debería pedir números del 1 al 10 hasta obtener uno válido. Pero hay algo mal con la condición del while...
int numero;
bool valido;

do
{
    Console.Write("Número del 1 al 10: ");
    valido = int.TryParse(Console.ReadLine(), out numero);

    if (!valido || numero < 1 || numero > 10)
    {
        Console.WriteLine("❌ Inválido. Reintenta.");
        valido = false;
    }

} while (valido);   // ← algo está mal aquí
Cambiar a while (!valido);
Cambiar a while (numero > 10);
Quitar el while y dejar solo }
Cambiar a while (valido == true);
🏆
Anatomía de un bucle infinito
Los bucles infinitos casi siempre vienen de 3 errores: (1) olvidar actualizar la variable de control, (2) no cambiar la bandera cuando corresponde, (3) escribir mal la condición del while (inversión lógica). Revisa siempre estos 3 puntos antes de ejecutar.
